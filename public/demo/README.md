# Книги комплекта

Шесть изданий [Standard Ebooks](https://standardebooks.org/), с которых начинается полка.
Тексты — общественное достояние; работа Standard Ebooks над ними отдана в
[CC0](https://creativecommons.org/publicdomain/zero/1.0/). Файлы взяты как есть, за одним
исключением: обложка в каждом ужата до 600 px по ширине (из неё берётся один цвет для корешка).
